# Personal Finance Tracker

A simple personal finance management application for tracking income,
expenses, budgets, and financial activity.

## Features

- Add income and expenses
- Edit transactions
- Delete transactions
- Search transactions
- Filter by category
- Filter by date
- Monthly budget tracking
- Budget progress indicator
- Income and expense summaries
- Balance calculation
- Persistent data using Local Storage
- Financial charts and analytics
- Responsive interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage
- Chart.js

## How It Works

The application stores transaction data in the browser's Local Storage.
Users can add, edit, delete, search, and filter transactions.

The dashboard automatically calculates:

- Total income
- Total expenses
- Current balance
- Monthly spending
- Remaining budget
- Budget usage percentage
